# Arduino Person/Object Following Robot


# Overview

This is an Arduino-based Person/Object Following Robot that can move in multiple directions (left, right, forward, backward, and stop) based on hand gestures or object positioning. The robot is designed to follow a nearby object or person and halt when the object moves away.

 # Components Used

Arduino Uno (Microcontroller)

Ultrasonic Sensor (For distance measurement and obstacle detection)

Two IR Sensors (For line tracking and object detection)

Motor Shield (To control the motors)

4 Gear Motors (For movement)

1 Servo Motor (For sensor movement and tracking)

4 Tires (For mobility)

Acrylic Sheet (Base structure)

Jumper Wires (Connections and circuit setup)

# Features

Person/Object Following: The robot follows the closest detected object/person using the ultrasonic sensor.

Multi-Directional Movement: Moves forward, backward, left, right, and stops based on object movement.

Gesture-Based Stopping: Stops when the object moves away beyond a specific distance.

Arduino Controlled: Uses an Arduino Uno with a motor shield for smooth operation.
